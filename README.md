# TravelGieni.com

Initial TravelGieni destination-discovery application.

## V1 scope

- Europe destination seed catalogue
- Deterministic, non-LLM ranking
- Filters for month, trip length, budget style and travel interests
- Transparent recommendation reasons and trade-offs
- No flights, hotels, booking, authentication or AI yet

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deployment

Import the GitHub repository into Vercel. Vercel should detect Next.js automatically.
